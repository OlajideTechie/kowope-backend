# Permissions & Access Control

This document defines role-based permissions for the platform.

## Roles
- Driver
- Agent
- Admin
- Super Admin

---

## Driver Permissions
- Can authenticate via phone number + OTP
- Can view own profile
- Can generate daily tickets
- Can view own ticket history
- Cannot view other drivers
- Cannot modify fees

---

## Agent Permissions
- Can authenticate via phone number + OTP
- Can generate tickets for drivers
- Can view tickets generated by self
- Cannot change system configuration
- Cannot manage admins

---

## Admin Permissions
- Can view all drivers
- Can view all agents
- Can view tickets and payments
- Can activate / deactivate drivers or agents
- Cannot change system-wide fees

---

## Super Admin Permissions
- All Admin permissions
- Can manage fee configuration
- Can manage admin accounts
- Can perform system-level overrides

---

## Enforcement Strategy
- Role is enforced via request.user.role
- Permissions are enforced using Django REST Framework permissions
- Sensitive actions require explicit role checks
